# Задача ЛР3

**Нова функція: «Бюджет місяця».** Користувач задає місячний бюджет. Після збереження операцій застосунок показує, скільки витрачено, скільки лишилось, денний ліміт до кінця місяця, розподіл за категоріями та попередження на 80% і 100% бюджету. Розрахунок виконує backend, щоб правила (пороги, що рахується витратою) були однакові для всіх клієнтів. Функція зачіпає два компоненти: backend і mobile.

Однаковий текст задачі використано для обох планів (без контексту і з Knowledge Base).
