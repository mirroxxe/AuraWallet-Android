# План без контексту

**Умови:** prompt містить лише текст задачі з `task.md` і фразу «це Android-застосунок для обліку витрат з backend», без файлів репозиторію й `docs/`. Щоб відтворити, надішліть prompt нижче в новий чат з AI-асистентом без прикріплених файлів.

**Prompt:**
> Ми розробляємо Android-застосунок для обліку витрат з backend. Додай функцію «Бюджет місяця»: користувач задає місячний бюджет, застосунок показує витрачене, залишок, денний ліміт, розподіл за категоріями та попередження на 80% і 100%. Склади план реалізації.

**Відповідь AI (план):**
1. Додати в Android локальну базу Room: таблиці `Budget` і `Expense`, DAO, міграцію БД.
2. Підключити Hilt для впровадження залежностей; створити `BudgetRepository`, `GetBudgetUseCase`, `SetBudgetUseCase`.
3. Створити окремий екран `BudgetScreen` і додати Navigation Compose з нижнім меню.
4. Дозволити задавати ліміт для кожної категорії окремо, а також загальний ліміт.
5. На backend (Node.js + Express) створити таблиці `budgets` і `expenses` у PostgreSQL, endpoints `GET/POST /budgets`, `GET /expenses?month=`.
6. Додати автентифікацію JWT, щоб бюджети були прив'язані до користувача.
7. Надсилати push-сповіщення через Firebase Cloud Messaging на 80% і 100%.
8. Щодня WorkManager перевіряє бюджет і надсилає нагадування.
9. Написати unit-тести для use cases і інтеграційні тести API.
10. Оновити дизайн усього застосунку під Material You.

Файли: «будуть створені нові модулі `data`, `domain`, `presentation`», конкретних шляхів немає.
