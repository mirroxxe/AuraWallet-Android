## Відомі обмеження вихідної версії
- Модель не знає звичок конкретного користувача: «Епіцентр» завжди «Покупки», хоча цей користувач щоразу виправляє на «Житло»; рідкісні магазини («Майстерня шоколаду», «Книгарня Є», «пральня») отримують низьку впевненість → «Інше».
- Виправлення користувача (ЛР4: `chosen_category` у Room) зберігаються, але ніяк не впливають на наступні прогнози — користувач виправляє одне й те саме знову.
- «квиток на потяг» → «Інше» з першою альтернативою «Подорожі» (малий датасет).
