# AI component

## Призначення
Визначити категорію операції з короткого опису й пояснити вибір. Сума, валюта й магазин виділяються правилами (не AI).

## Модель
- `sklearn.Pipeline`: `FeatureUnion(TF-IDF char_wb 2–5, TF-IDF word 1–2)` → `LogisticRegression(C=12)`.
- Дані: `backend/app/ai/training_data.csv`, 201 вигаданий приклад, 17 категорій (uk + en).
- Навчається при старті сервісу (~0,1–0,2 с), зберігається в пам'яті; файлу моделі немає.
- Працює офлайн, без ключів і зовнішніх API.

## Персоналізація (ЛР6)
`backend/app/ai/personalizer.py`, без перенавчання моделі:
1. **Підготовка** `prepare()`: до 50 виправлень користувача → опис без суми (`parse().cleaned_text`), нижній регістр, дублікати й описи з < 3 літер відкидаються.
2. **AI-обробка** `best_match()`: вектори в символьному TF-IDF-просторі моделі (`classifier.embed()`), косинусна схожість запиту з кожним виправленням, найкращий збіг.
3. **Результат** `decide()`: якщо схожість ≥ `AI_PERSONAL_MIN_SIMILARITY` (0.50) і категорія відрізняється від прогнозу моделі (або модель невпевнена) — категорія користувача, `confidence_source = personal`, `confidence` = схожість; прогноз моделі — перша альтернатива. Інакше — результат моделі без змін.

`confidence` при `personal` — це схожість описів, а не ймовірність того, що категорія правильна; mobile підписує його «Схожість з вашою операцією». Оцінка: `docs/lab6/results.md` (персональні запити 33 % → 83 %, контрольні без змін).

## Вхід / вихід
- Вхід: `cleaned_text` — опис без суми й валюти (від `parser.parse`).
- Вихід (`Prediction`): `category`, `confidence`, `alternatives` (топ-3), `keywords` (слова з найбільшою позитивною вагою для класу, без службових слів).

## Пояснення
`service._explain()` формує текст: «Схоже на «Кава» (95%) на основі ключових слів «кава», «aroma kava». Магазин: Aroma Kava.»

## Обмеження
- Персоналізація порівнює описи, а не зміст: «Епіцентр ресторан» → «Житло», «нова сукня» ≈ «Нова пошта» (див. `docs/lab6/results.md`).
- Малий синтетичний датасет: нові магазини й рідкісні формулювання → низька впевненість (напр. «квиток на потяг» 0,29).
- Не розуміє контексту довгих речень і заперечень.
- Сума без валюти вважається гривнями; з кількох чисел без валюти береться останнє.
- Пояснення — ваги слів, а не причинно-наслідкове міркування.

## Fallback
| Ситуація | Поведінка |
|---|---|
| `confidence < AI_MIN_CONFIDENCE` (0,30) | `category = other`, `low_confidence = true`, альтернативи; mobile просить обрати вручну і блокує «Зберегти», поки не обрано |
| модель не завантажилась / виняток у `predict` | 503 `ai_unavailable`; mobile показує повідомлення й «Повторити» |
| `AI_SIMULATE_FAILURE=true` | штучний 503 для тестування |

## Відтворення
- Модель: `training_data.csv` (201 приклад), `LogisticRegression(C=12, max_iter=3000)`, scikit-learn з `requirements.txt`; навчання детерміноване.
- Параметри: `AI_MIN_CONFIDENCE=0.30`, `AI_PERSONAL_MIN_SIMILARITY=0.50` (`.env`).
- Оцінка: `cd backend && python -m eval.evaluate` (набори в `backend/eval/`).

## Як змінювати
Додати приклади в `training_data.csv` (формат `text,category`), перезапустити сервер, прогнати `pytest -q` і `python -m eval.evaluate`.
