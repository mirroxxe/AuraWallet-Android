## Готові відповіді
- **Чим фінальна версія відрізняється від MVP (ЛР2)?** Історія в Room, бюджет місяця, черга «очікує», шари ui/domain/data з інтерфейсами й тестами без backend, персоналізація AI, вибір будь-якої категорії.
- **Де виконується AI?** На backend FastAPI на ноутбуці; модель навчається при старті з CSV, без ключів.
- **Як оцінювали?** Top-1 accuracy на контрольних наборах `backend/eval/` (скрипти `evaluate.py`, `final_check.py`), регресія на прикладах ЛР2.
- **Як відтворюється збій?** Зупинити backend (мережа), `AI_SIMULATE_FAILURE=true` (збій AI), демо-режим «помилка» (fake).
- **Що змінилося після тестування?** DF1–DF5 (див. `defects.md`).
- **Які обмеження?** `known-limitations.md`, DF6.
