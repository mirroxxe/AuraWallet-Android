## Модель і параметри
| | |
|---|---|
| Алгоритм | `TfidfVectorizer(char_wb, 2–5, sublinear_tf)` + `TfidfVectorizer(word, 1–2)` → `LogisticRegression(C=12, max_iter=3000)` |
| Дані | `backend/app/ai/training_data.csv`, 201 синтетичний приклад, 17 класів; навчання при старті сервера (~0,2 с), детерміноване |
| Персоналізація | найближчий виправлений приклад за косинусною схожістю в символьному TF-IDF-просторі моделі; поріг `AI_PERSONAL_MIN_SIMILARITY=0.50` |
| Невпевненість | `confidence < AI_MIN_CONFIDENCE (0.30)` → «Інше», альтернативи, вибір вручну |
| Залежності | `backend/requirements.txt` (scikit-learn, numpy, fastapi, pydantic); зовнішніх AI-сервісів і ключів немає |

## Реакція на непридатний результат
- Модель невпевнена й схожого виправлення немає → «Інше» з позначкою, застосунок просить обрати категорію («Зберегти» неактивна, доки не обрано). Це **успішна обробка без придатного результату**, а не помилка: картка результату, а не картка помилки.
- Хибний збіг (#8) — відоме обмеження: користувач бачить плашку «Персоналізовано: як «Нова пошта»» і може змінити категорію; персоналізацію можна вимкнути чипом.
- Confidence при `model` — ймовірність класу; при `personal` — схожість описів. Жодне з чисел не є гарантією правильності; 7/8 характеризує лише ці 8 прикладів.
